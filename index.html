In progress

  • Ulana release in progress

    A compiler that turns WebAssembly into Luau, so programs written in C, Rust or Go, such as SQLite, QuickJS and zstd, run as plain Luau.

    A Rust and CUDA engine that runs whole brain wiring maps as live simulations. It matches a validated scientific reference bit for bit, runs a 165,000-neuron nervous system faster than real time on one consumer GPU, and drives a physics model of the body.

    A command-line check that finds silent slowdowns in self-hosted LLM serving. Every rule comes from a measured case.
